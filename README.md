# RetailPro - Consultas con JOINs

Entrega del Módulo 5 del curso de Data Analytics de Coderhouse (SQL Server / T-SQL).

## Archivos

- `m5_consultas_joins.sql`: consultas con JOINs y UNION ALL sobre la base `Ventas_Tech_DB` (creada en el Módulo 3).

## Consultas

1. Vista base del proyecto: ventas cruzadas con clientes, productos y categorías (INNER JOIN).
2. Clientes registrados sin ventas (LEFT JOIN).
3. Productos sin ventas (LEFT JOIN).
4. Facturación consolidada por canal: presencial (Buenos Aires) vs. online (interior) (UNION ALL).

Debajo de cada consulta está el hallazgo principal.

## Cómo ejecutarlo

1. Tener creada la base `Ventas_Tech_DB` (script `ventas_tech_db.sql` del Módulo 3).
2. Abrir `m5_consultas_joins.sql` en SSMS y ejecutarlo (F5).
